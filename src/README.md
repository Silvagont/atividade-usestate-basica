# Atividade 1 — React: Estado e Interatividade

Implementação das missões da atividade guiada de `useState`:

- Missão 1: contador com botões para aumentar e diminuir.
- Missão 2: mostrar e esconder um aviso com estado booleano.
- Missão 3: campo de texto controlado e saudação.
- Desafio final: cartão de boas-vindas com saudação que pode ser escondida.
- Desafio extra: contador que para na meta 10, exibe mensagem e pode voltar a zero.

## Como executar

Requer Node.js compatível com a versão atual do Vite.

```bash
npm install
npm run lint
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

Depois, publique o repositório no GitHub e envie o link no AVA, conforme as instruções da atividade.
